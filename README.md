# 📚 Tổng hợp các file code ptit

Kho lưu trữ tổng hợp mã nguồn giải các bài tập trên nền tảng hệ thống thực hành Code PTIT và Db PTIT. Dự án được phân loại chi tiết theo từng môn học và ngôn ngữ lập trình.

## 📂 Cấu trúc dự án

Dự án được chia tương ứng với từng môn học như sau:

*   **`cpp/`**: Ngôn ngữ lập trình C++.
*   **`csdl-sql/`**: Cơ sở dữ liệu (sử dụng sql).
*   **`dsa-cpp/`**: Cấu trúc dữ liệu và giải thuật (sử dụng C++).
*   **`oop-java/`**: Lập trình hướng đối tượng (sử dụng Java).
*   **`thcs2-c/`**: Tin học cơ sở 2 (sử dụng C).

Trong mỗi thư mục, các file code thường được đặt tên theo **Mã bài tập** (ví dụ: `DSA01001.cpp`, `J01001.java`...) hoặc **Tên bài tập** để tiện cho việc tìm kiếm.

> **⏳ Trạng thái cập nhật:** Hiện tại mình đang cập nhật **`oop-java`**, **`csdl-sql`**, các bài code trong phần này sẽ được cập nhật thêm trong tương lai.
